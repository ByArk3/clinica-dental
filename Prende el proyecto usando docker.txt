PRENDE EL PROYECTO USANDO DOCKER
Clínica Dental — Grupo 1
================================

Carpeta del proyecto: D:\Proyectos\clinica-dental (en otra PC puede ser C:\Proyectos\clinica-dental:
cambiar la letra en los comandos).

¿PC NUEVA, SIN NADA? Hacer primero la sección «DESDE CERO» del final y luego volver aquí.

Antes de empezar: abrir Docker Desktop y esperar a que diga que está corriendo.
Todos los comandos van en PowerShell, uno por uno y en este orden.


1. Ir a la carpeta del proyecto
-------------------------------
cd D:\Proyectos\clinica-dental


2. Traer lo último de GitHub
----------------------------
git pull origin main


3. Revisar el archivo .env
--------------------------
Abrir el proyecto en VS Code:

code .

En el panel izquierdo está el archivo .env (junto a docker-compose.yml). Revisar que tenga:
  - SEED=true             (carga los usuarios de prueba y 3 meses de historia ficticia: citas,
                           cobros, pedidos. Solo en una base vacía: por eso el paso 4, docker compose down -v)
  - SESSION_SECRET        puede quedar vacío; el contenedor genera uno solo
  - Los datos de SMTP (Gmail) y RENIEC_TOKEN

Si se prefiere el Explorador de Windows:

explorer .

(El .env empieza con punto: si no aparece, activar en Vista -> Mostrar -> Elementos ocultos.)


4. Apagar lo anterior y borrar la base vieja
--------------------------------------------
docker compose down -v

OJO: el -v borra los datos guardados en Docker; la base se crea de nuevo con los datos de ejemplo.
Para conservar lo registrado, usar solo: docker compose down


5. Construir la imagen del backend
----------------------------------
docker build -f backend/Dockerfile -t clinica-dental-api .


6. Construir la imagen del frontend
-----------------------------------
docker build -f frontend/Dockerfile -t clinica-dental-web .


7. Levantar el sistema
----------------------
docker compose up

Esperar a que la API diga que está escuchando en el puerto 3000.


8. Abrir en el navegador
------------------------
http://localhost:8080

PARA APAGARLO
-------------
Ctrl + C en la ventana donde corre, y luego:

docker compose down


NOTAS
-----
- Se construye cada imagen por separado (pasos 5 y 6) porque "docker compose up --build"
  puede fallar en Windows con un error de "bake".
- Si un paso da error, sacar captura de la ventana de PowerShell.


DESDE CERO (PC nueva que solo tiene Docker Desktop)
===================================================
Una sola vez. En PowerShell, uno por uno:

a) Instalar Git:
   winget install --id Git.Git -e --source winget
   Cerrar PowerShell y abrirlo de nuevo. Comprobar:  git --version

b) Crear la carpeta y descargar el proyecto:
   mkdir C:\Proyectos\clinica-dental
   cd C:\Proyectos\clinica-dental
   git clone https://github.com/ByArk3/clinica-dental.git .
   (el punto final descarga dentro de esta carpeta; si pide iniciar sesión en GitHub, aceptar)

c) Crear el archivo .env (es un ARCHIVO, no una carpeta):
   Copy-Item .env.docker.example .env
   notepad .env
   Revisar que diga:  SEED=true   y   COOKIE_SECURE=false
   OJO: con COOKIE_SECURE=true no se puede iniciar sesión en http://localhost (solo sirve con HTTPS).
   Si el Bloc de notas lo guardó como .env.txt:  Rename-Item .env.txt .env

d) Seguir con los pasos 5, 6 y 7 de arriba (no hace falta el paso 4: la base es nueva).
